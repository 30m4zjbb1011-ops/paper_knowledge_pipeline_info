Privacy policy

Last updated: 9 October 2026

Paper Knowledge Pipeline is a personal research utility. This policy describes the current workflow for retrieving selected research PDFs from Google Drive, parsing them with MinerU, reviewing the results, and storing outputs on Drive.

Data accessed and why

The workflow accesses selected PDF contents and the file and folder information needed to find, download, and organize those documents and their outputs. It processes extracted text, references, images, Markdown, JSON, and archives to build a reviewed personal research library.

Drive permission is broad. The configured Google OAuth scope is https://www.googleapis.com/auth/drive. It permits access beyond the designated pipeline folders. Restricting normal operation to those folders is an intended workflow boundary, not a folder-only OAuth permission.

Where data goes

  • Google Drive: holds source PDFs, raw parsing results, and reviewed outputs in the operator's designated folders.
  • GitHub Actions: runs the manually triggered workflow, downloads selected files, and transfers files and results between services.
  • MinerU API: receives selected PDFs for parsing and returns extracted content and associated files.
  • Review: the operator and any assistant tools they choose to use may access the extracted content to repair it and separate Main and References Markdown. Using an external assistant can disclose that content to its service provider.

These providers process data under their own terms and policies. This policy does not promise a particular provider retention period, deletion outcome, or absence of provider access. The implemented pipeline does not currently send content to Dify or invoke paid LLM processing.

Credentials and access

The operator stores Google OAuth credentials and the MinerU API token in GitHub Actions Secrets for use by the workflow. They are not part of these public information pages. Access to the repository, workflow, Secrets, and Drive folders should be limited to authorized people. No security measure can guarantee that unauthorized access will never occur.

Storage, retention, and deletion

Source documents, raw results, and reviewed outputs remain in Drive until the operator removes them. This workflow description does not specify an automatic deletion schedule. Workflow logs, temporary processing files, and provider-side copies may be subject to each platform's settings and retention practices.

To stop future access, remove the application's Google authorization using Google's linked-app instructions, and remove the relevant GitHub Actions Secrets. Stop any active workflow runs as needed. Revocation or removing Secrets does not erase documents or results already downloaded or stored.

Delete stored source files and outputs separately from Drive and other locations you control. Review GitHub and MinerU controls and policies for any copies retained by those services.

This public website

These static pages contain no sign-in flow, upload form, advertising, analytics scripts, or application cookies. Visiting them does not authorize Google Drive access or start document processing. The website host may process ordinary request information, such as an IP address and browser details, under its own privacy policy.
