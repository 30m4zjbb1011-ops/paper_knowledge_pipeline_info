Personal research utility

From research PDFs to reviewed knowledge.

Paper Knowledge Pipeline converts selected papers from Google Drive into structured files, then supports human and assistant review before they are used in a personal research library.

This is an information page. It does not sign you in, accept document uploads, or run the pipeline.

How the workflow works

  1. Select and run. The operator manually starts a GitHub Actions workflow to retrieve selected PDFs from an authorized Google Drive account.
  2. Parse with MinerU. The selected PDFs are sent to the MinerU API for document parsing. Returned files can include Markdown, JSON, images, and ZIP archives.
  3. Review and organize. Human and assistant review repairs extracted content and separates the main paper and references into Main and References Markdown files.
  4. Store on Drive. Raw parsing results and reviewed outputs are stored in the operator's designated Google Drive pipeline folders.

Google Drive access

The application currently requests the full Google Drive OAuth scope. That permission is broader than the designated pipeline folders; the intended workflow is confined to those folders. Selected documents are processed by GitHub Actions and MinerU, so processing is not limited to Google Drive.

Read the privacy policy for the data flow, third-party processing, storage, and ways to stop access.

Current scope

The implemented pipeline is a manually triggered personal research workflow. It does not currently include paid LLM processing or a Dify integration.

Only process documents you are authorized to use and share with the services involved.
